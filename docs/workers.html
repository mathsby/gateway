Workers

Get workers for a site

Returns every worker on record for a given site. Each worker describes one person staffed at the site — their name, role, and current status.

GET /sites/{siteId}/workers 100 req/min per caller

Path parameters

NameTypeDescription
siteIdrequired uuid The site to fetch workers for.

Request

curl https://client-gateway-api.onrender.com/sites/3fa85f64-5717-4562-b3fc-2c963f66afa6/workers
const res = await fetch(
  `https://client-gateway-api.onrender.com/sites/${siteId}/workers`
);
const workers = await res.json();
import requests

res = requests.get(f"https://client-gateway-api.onrender.com/sites/{site_id}/workers")
workers = res.json()

Fields

iduuidUnique identifier for the worker record.
siteIduuidEchoes the requested site.
namestringName of the worker.
rolestringThe worker's role at the site, e.g. Electrician.
statusstringOne of Active, OnLeave, Inactive.
Returned when no site matches siteId. application/problem+json 
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.5",
  "title": "Site not found",
  "status": 404,
  "detail": "No site exists with id '00000000-0000-0000-0000-000000000000'."
}
Returned once the rate limit is exceeded. application/problem+json 
{
  "title": "Too Many Requests",
  "status": 429
}

Also sets a Retry-After: 60 header.

Rate limits

Each caller (tracked by IP address) may make up to 100 requests per rolling minute. There is no queueing — the 101st request in a window is rejected immediately with a 429 and a Retry-After header telling you how many seconds to wait.
